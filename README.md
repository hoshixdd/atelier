# HOSHIIXDD

Cinematic portfolio atelier of [Jude Mendoza](https://github.com/hoshixdd) — creative developer and AI engineer.

A persistent Three.js belt. Named worlds are rooms of work. Unnamed worlds keep letters. Touch a planet to enter.

## Stack

- TanStack Start + Vite
- Three.js (bloom, remnant, planets)
- Tailwind CSS v4
- Web Audio (procedural score)

## Develop

```bash
npm install
npm run dev
```

Open the local preview, enter the atelier, look up.

## Build

```bash
npm run typecheck
npm run build
```
